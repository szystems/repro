## 2. Detalle de desarrollos adicionales

### Ítem 1 — Agregar servicio a una orden ya creada

**Situación:** Un mismo candidato necesita, por ejemplo, Polígrafo y después Estudio Socioeconómico, dentro de la **misma orden**, sin duplicar trámites innecesarios.

Se ofrecen **dos niveles** (elija uno):

#### Opción 1A — Versión práctica · **Q 3,500.00**

| Incluye | No incluye |
|---------|------------|
| Botón **“Agregar servicio”** en la orden existente | Reutilización automática de todo el formulario ya llenado |
| Mismo candidato (DPI), **nuevo servicio** en la misma orden | Expediente único avanzado |
| Datos básicos **prellenados** (nombre, DPI, correo, teléfono, etc.) | |
| Nueva **autorización** y **estados independientes** por servicio | |
| Flujo operativo claro para REPRO y candidato | |

**Tiempo estimado:** 2 a 3 semanas  

**Recomendada si:** necesitan resolver el caso **pronto** y pueden aceptar que el candidato complete el flujo del nuevo servicio (autorización + formulario según aplique).

---

#### Opción 1B — Versión completa · **Q 6,500.00**

| Incluye todo lo de 1A, más: |
|-----------------------------|
| **Reutilización** de información ya capturada (no volver a pedir datos personales, familia, laboral, etc.) |
| Solo **autorización del nuevo servicio** + **campos complementarios** (ej. bloque socioeconómico) |
| Vista de **expediente unificado** por candidato dentro de la orden (servicios Polígrafo / VSA / Socio en un solo lugar) |
| Reglas para no crear candidatos duplicados |

**Tiempo estimado:** 5 a 7 semanas  

**Recomendada si:** la prioridad es **no molestar al candidato** con formularios repetidos y unificar la operación a mediano plazo.

> **Nota:** Solo se contrata **1A o 1B**, no ambas.
